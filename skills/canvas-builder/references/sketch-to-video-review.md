# Sketch to H3 and review

- On a blank canvas, use `vd_canvas recipe {recipe:"sketch-to-h3",expectedDraftRevision,assetId,brief,apply:true}` to build the draft in one validated edit. Omit `apply` for a plan. Use the wiring below to adapt an existing graph.
- Use a Sketch Input and Text Input. Choose a ComfyUI image-edit node whose Reference port accepts `sketch`. Connect the sketch to Reference and the Text Input to the image node's enabled Prompt field. A text-only generator cannot use a sketch. Preview the finished reference.
- Add H3 as `kind:"video-generation"` with `workflowId:"builtin-minimax-h3-reference-to-video-turbo"` so users can switch presets. Branch the finished image to both the Ollama Prompt Enhancer's Reference input and the H3 Reference input. Use an installed Ollama model with vision support. Tell it to use the image as `Picture 1`, preserve what is visible, and output only a short H3 reference-to-video prompt. Specify the intended duration, visible subject, motion, camera, and sound. Connect the enhancer's **text output** to the enabled H3 Prompt field, and connect the H3 video output to Preview. Use H3 Reference to Video for visual guidance; use first-frame mode only when the still must be the literal opening frame.
- Set the H3 node's numeric `data.duration` to match the enhancer's requested clip length. The text alone does not change the rendered duration. Verify the finished MP4 duration; H3 may round to its frame grid.
- On an authorized shared accelerator with tight memory, use Flow links to order release nodes: ComfyUI image → `comfyui-clear` → Ollama → `ollama-eject` → H3. Keep the direct image and text links. If the same machine will run the vision review, `comfyui-clear` after H3 can make room for it. Releases affect the configured endpoints; do not unload unrelated workloads or insert these nodes for separate accelerators without a need.
- Validate before running. Follow the exact `runId`; check that the image, enhanced text, and video actually completed. Use the corresponding output asset IDs, never the input sketch or a stale prior run. Stop and report the failed stage if a provider fails.
- For chat review, use `vd_canvas media {assetId:videoId,operation:"video-contact-sheet",options:{frameCount:6,columns:3}}`. It returns one image asset plus ordered sample times. On an image-capable chat model, call `vd_canvas image` on the reference image and contact sheet, or open the current workflow's Gallery previews and choose **Add to chat** for the image and **Add frames to chat** for the video. Request a caption, an observed summary, and a comparison. The tiles run left to right, top to bottom. Identify reference versus video explicitly; do not infer sound or events between frames. Ask for audio analysis separately if needed.
